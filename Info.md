# 🏠 House Price Prediction

## Kevin C George

A Machine Learning project that predicts house prices based on house features using **Python, Pandas, Scikit-learn, Random Forest, and Streamlit**.

---

## 📌 Project Overview

This project uses Machine Learning to predict the selling price of a house.

The project takes house information such as:

- Living area
- Number of rooms
- Year built
- Lot area
- Neighborhood
- Garage information
- And other available house features

The trained Machine Learning model predicts the expected house selling price.

The project also includes a **Streamlit web application** where users can enter house details and receive a predicted house price.

---

## 🎯 Project Goal

The goal of this project is to:

1. Load a real-world house price dataset
2. Understand and analyze the data
3. Separate features and target
4. Split the data into training and testing sets
5. Handle missing values
6. Handle categorical data
7. Train a Machine Learning model
8. Make predictions
9. Evaluate the model
10. Create an interactive Streamlit application
